## 1. Project Overview

**NEXORA** is a modern digital workspace tailored for engineering teams to manage projects, tasks, team collaboration, and productivity tracking with zero external frameworks.

### Milestone 1 Deliverables:
- **Responsive Layout:** Engineered across viewports: 320px, 375px, 390px, 414px, 480px, 768px, 1024px, 1280px, 1440px, 1920px.
- **Header & Navigation:** Responsive desktop navigation with mobile hamburger drawer and accessible toggle.
- **Hero Section:** High-impact technical copy, primary/secondary call-to-actions, and lightweight HTML/CSS product preview.
- **Four Core Features:** Project Management, Team Collaboration, Task Tracking, Productivity Insights.
- **Visual Metrics Strip:** 120+ Projects, 48 Teams, 2.4K Tasks, 94% Completion demonstration statistics.
- **Semantic HTML5 & Accessibility:** Proper landmark hierarchy (`header`, `nav`, `main`, `section`, `footer`), visible focus states, and descriptive touch targets.
